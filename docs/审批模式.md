# 审批模式（AuraX #13）

对话和任务输入区共用三档单选菜单：请求批准、帮我批准、完全访问权限。
规则由 AuraClaw 决定，适用于所有需要审批的操作，write 只是示例。

- 新对话（streaming）默认请求批准。
- 任务页同步、异步提交后等待结果（non_streaming）默认完全访问权限；执行轨迹 SSE 不改变此默认。
- 帮我批准先自动审核，无法确认安全时转人工；完全访问权限免逐次人工批准，后端 deny 仍生效。
- 显式选择只作用当前草稿/下一 Run。新建草稿恢复对应默认，不保存全局“完全访问权限”偏好。
- Session 模式以服务端返回为准，运行中/待审批不能切换来绕过当前审批；历史缺字段显示旧版策略。
- 草稿模式仅保存在内存，并按环境、身份、Session、调用类型隔离；重新载入由后端恢复有效模式。
- SDK 先协商 GET /v1/approval-modes；旧后端显示不支持，不假报设置成功。
- 409 needs_human/needs_resume 作为可恢复结果处理，其余冲突仍抛错；禁止自动以 full_access 重试。

菜单支持键盘、窄窗口、选中状态与橙色全权限提示。自动审核进度/通过/转人工来自后端 Activity，
不显示模型内部思考，也不在客户端代点批准。关窗与断开 SSE 不取消任务或改变审批模式。

依赖后端先部署 AuraClaw #92 / 0059 迁移。接口与升级约束见 AuraClaw docs/operations/approval-modes.md。
