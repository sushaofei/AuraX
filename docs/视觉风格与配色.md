# AuraX：暖纸色工作台

参考用户提供的 Discovery Loop 首页截图，提取暖纸色、墨黑、少量紫色和轻边界；不是复制其品牌标识、素材或首页布局。色值为 AuraX 的适配选择，并非官网源码的精确取色。

## 设计变量

定义于 `apps/desktop/src/styles.css` 的 `:root`：

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F4EFE7` | 主背景，取消大面积背景渐变 |
| `--surface` | `#FCFAF6` | 卡片与输入区域 |
| `--paper-2` | `#EBE5DC` | 次级区域、标签与代码底色 |
| `--ink` | `#1D1C19` | 标题、正文、用户消息 |
| `--mist` | `#676158` | 辅助文字；为小字号可读性加深 |
| `--border` | `#DDD6CC` | 轻量边框 |
| `--accent` | `#75429B` | 主按钮、链接与选中态 |
| `--accent-soft` | `#EEE5F3` | 选中导航、能力图标底色 |

旧变量 `--amber` / `--copper` 暂保留为紫色变量的别名，避免现有组件断开主题引用。后续组件优先使用语义变量。

## 应用规则

- 保留现有工作台布局、侧栏宽度、输入区域和执行轨迹拖拽行为，不使用宣传首页的大字与巨幅留白。
- 导航使用暖浅色；执行轨迹使用暖炭黑，与内容区形成明确分区。
- 渐变只用于少量发送按钮、进度和品牌装饰，不铺满页面或每张卡片。
- 正文、说明和中文标题使用系统无衬线字体；诊断信息保留等宽字体。无新增字体或素材网络请求。
- 成功、警告、失败继续使用绿色、赭色和红色，保留文字说明，不用紫色覆盖语义状态。
- 阴影降低，只在输入框和轨迹区保留轻层次。键盘焦点使用紫色轮廓，支持减少动态效果偏好。

## 验证

`e2e/theme.spec.ts` 检查实际渲染的导航、辅助文字、主按钮和轨迹正文对比度（至少 4.5:1），并遍历六个工作台页面检查横向溢出、焦点与 reduced-motion。
这些断言覆盖关键配色组合，并不代表完整的无障碍审计。

本轮为前端视觉改造，无接口、数据、身份或任务生命周期变更。部署新版 AuraX 后生效，不需要重启 AuraClaw。
