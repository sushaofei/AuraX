# 开发阶段校验清单

本清单是 AuraX v1（[Issue #1](https://github.com/sushaofei/AuraX/issues/1)）的完成门禁。阶段只有在功能、架构、质量和交付项全部通过后，才允许标记完成、提交 Git 并推送远端。

## 通用阶段门禁

- [x] 阶段范围与不包含范围已明确（定时、完整登录、Skill 发布不在 v1）。
- [x] 功能列表逐项完成，并有对应测试或可复现验证证据。
- [x] Session 事实在 AuraClaw；AuraX 只发命令、查投影、订 SSE。
- [x] 身份头、幂等键、`credential_ref`、关窗不 cancel 已检查。
- [x] 不涉及 AuraX 自有数据库 Schema；本机仅缓存连接 / 草稿 / last session（可丢）。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm e2e` 全部通过。
- [x] README、AGENTS、签名说明已同步。
- [x] Git 暂存范围已审查，不包含 `.env`、证书、缓存或 Secret。

## Phase 0 — 仓库与壳

- [x] pnpm workspace、TS strict、eslint、vitest。
- [x] Tauri 2 macOS 空窗；展示名 AuraX，Bundle ID `app.aurax.desktop`。
- [x] `claw-sdk` 注入 `MOCK_IDENTITY`（`platform` / `local-org` / `local-user`）与幂等键。
- [x] 连接设置只改 AuraClaw base URL，无账号切换。

## Phase 1 — 实时对话

- [x] 创建任务（`source=chat`）、SSE、transcript / result 回填、追问、取消、关闭。
- [x] HITL 卡片走审批命令；`waiting_for_human` 不能当普通追问。
- [x] 断线用 `Last-Event-ID` 重连；流结束不是任务失败。
- [x] 关闭窗口不会调用 cancel。

## Phase 2 — Session 历史

- [x] 历史走 `GET /v1/tasks?kind=chat`；本机索引仅缓存。
- [x] 打开即恢复 transcript；paused / retry_wait 可 resume（非人审）。

## Phase 3 — MCP 管理

- [x] 登记 / 探测 / 启停 / 对账 / 退役 / Catalog tools。
- [x] Secret 只填 `credential_ref`；loopback 相对 Credential Proxy。
- [x] 不直连 AuraMCP，不调用 `/internal/v1/*`。

## Phase 4 — Skill 管理

- [x] 目录、详情、`SKILL.md`、租户启停。
- [x] 对话页 Skill 选择器（租户目录，下一轮 Run 生效）。
- [x] 无发布入口。

## Phase 5 — 定时任务

- [x] 不在 v1 实现。无本机 cron / 菜单栏调度 / 漏跑补跑。等 AuraAPI Timer。

## Phase 6 — 打包与门禁

- [x] 签名/公证准备：ad-hoc `signingIdentity: "-"`、`Entitlements.plist`、macOS 13+；真实证书步骤见 `docs/macos-signing.md`。
- [x] 关键路径 Playwright：工作台导航、模拟身份、MCP 无明文 Secret、关窗路径不 cancel、不打内部 API。
- [x] 本阶段校验清单已记录。
- [x] GitHub Actions：`typecheck` / `lint` / `test` / `e2e`。
