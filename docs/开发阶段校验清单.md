# 开发阶段校验清单

本清单是 AuraX v1（[Issue #1](https://github.com/sushaofei/AuraX/issues/1)）的完成门禁。阶段只有在功能、架构、质量和交付项全部通过后，才允许标记完成、提交 Git 并推送远端。

## 通用阶段门禁

- [x] 阶段范围与不包含范围已明确（定时、完整登录、Skill 发布不在 v1）。
- [x] 功能列表逐项完成，并有对应测试或可复现验证证据。
- [x] Session 事实在 AuraClaw；AuraX 只发命令、查投影、订 SSE。
- [x] 身份头、幂等键、`credential_ref`、关窗不 cancel 已检查。
- [x] 不涉及 AuraX 自有数据库 Schema；本机仅缓存连接 / 草稿 / last session（可丢）。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm e2e` 全部通过。
- [x] README、AGENTS、签名说明已同步。
- [x] Git 暂存范围已审查，不包含 `.env`、证书、缓存或 Secret。

## Phase 0 — 仓库与壳

- [x] pnpm workspace、TS strict、eslint、vitest。
- [x] Tauri 2 macOS 空窗；展示名 AuraX，Bundle ID `app.aurax.desktop`。
- [x] `claw-sdk` 注入 `MOCK_IDENTITY`（`platform` / `local-org` / `local-user`）与幂等键。
- [x] 连接设置只改 AuraClaw base URL，无账号切换。

## Phase 1 — 实时对话

- [x] 创建任务（`source=chat`）、SSE、transcript / result 回填、追问、取消、关闭。
- [x] HITL 卡片走审批命令；`waiting_for_human` 不能当普通追问。
- [x] 断线用 `Last-Event-ID` 重连；流结束不是任务失败。
- [x] 关闭窗口不会调用 cancel。

## Phase 2 — Session 历史

- [x] 历史走 `GET /v1/tasks?kind=chat`；本机索引仅缓存。
- [x] 打开即恢复 transcript；paused / retry_wait 可 resume（非人审）。

## Phase 3 — MCP 管理

- [x] 登记 / 探测 / 启停 / 对账 / 退役 / Catalog tools。
- [x] Secret 只填 `credential_ref`；loopback 相对 Credential Proxy。
- [x] 不直连 AuraMCP，不调用 `/internal/v1/*`。

## Phase 4 — Skill 管理

- [x] 目录、详情、`SKILL.md`、租户启停。
- [x] 对话页 Skill 选择器（租户目录，下一轮 Run 生效）。
- [x] 无发布入口。

## Phase 5 — 定时任务

- [x] 不在 v1 实现。无本机 cron / 菜单栏调度 / 漏跑补跑。等 AuraAPI Timer。

## Phase 6 — 打包与门禁

- [x] 签名/公证准备：ad-hoc `signingIdentity: "-"`、`Entitlements.plist`、macOS 13+；真实证书步骤见 `docs/macos-signing.md`。
- [x] 关键路径 Playwright：工作台导航、模拟身份、MCP 无明文 Secret、关窗路径不 cancel、不打内部 API。
- [x] 本阶段校验清单已记录。
- [x] GitHub Actions：`typecheck` / `lint` / `test` / `e2e`。

## Phase 7 — 产品级对话执行轨迹（[Issue #2](https://github.com/sushaofei/AuraX/issues/2)）

- [x] 产品方案明确 transcript/activity/result/operations timeline 边界。
- [x] SDK 支持 Activity 契约、增量游标和未知节点前向兼容。
- [x] 对话页右侧面板支持展开/收回、Run 分组、筛选和节点详情。
- [x] 窄窗口使用可关闭抽屉，不影响主对话可用性。
- [x] SSE 只触发 Query 刷新；刷新/重连从 Activity API 权威恢复。
- [x] localStorage 只保存展示偏好，不保存 Activity 详情。
- [x] loading、empty、error、unsupported、running、waiting、failed、cancelled 状态完整。
- [x] SDK tests、typecheck、lint、生产构建与 Playwright 关键路径通过。
- [x] README、产品方案和 AuraClaw API 文档同步。
- [ ] 本阶段 intentional commit 已完成并 push。

## Phase 8 — Skill 全生命周期管理（[Issue #4](https://github.com/sushaofei/AuraX/issues/4)）

- [x] SDK 拆分 Catalog、Installation、Publication、Package、Source、Publisher/Key 和 Admission DTO。
- [x] 修复旧启停契约：使用 Installation revision、reason code 与正确响应类型。
- [x] Catalog 页面展示服务端 availability、版本治理、SKILL.md 与依赖摘要。
- [x] Installation 支持 enable、disable、draining uninstall 与显式 force。
- [x] Source 支持创建、编辑、同步健康、显式同步和退役；Secret 仍仅使用 credential_ref。
- [x] Publisher 支持注册、公钥轮换/撤销和 suspend/resume/revoke；私钥不进入 AuraX。
- [x] 已签名小包使用 direct files，大包使用 canonical archive + staged single/multipart upload。
- [x] Publication revoke/restore、Package purge 与 Admission 指标/筛选/游标翻页已进入管理界面。
- [x] SDK unit/contract tests、TypeScript typecheck 与生产构建通过。
- [x] Playwright 覆盖 Skill 管理入口、禁止内部 API/直连 AuraMCP，并与既有关键路径共同通过。
- [x] 全仓 ESLint 通过；既有 ChatView hooks dependency 警告已记录但不阻断门禁。
- [ ] 在真实 AuraClaw/对象存储环境完成 direct/staged 发布、WebView CORS 与 multipart ETag 联调。
- [ ] 与 AuraClaw #59 的跨仓 E2E、完整门禁、intentional commit 和 push 完成。
